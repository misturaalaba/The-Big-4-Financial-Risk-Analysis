# 📊 Big Four Financial Risk Analysis Dashboard

## 🧾 Overview
This project presents an interactive financial risk analysis dashboard built in **Microsoft Excel**. It compares key performance and risk indicators across the Big Four firms: Deloitte, Ernst & Young (EY), KPMG, and PwC.

The dashboard provides a clear visual summary of revenue, fraud cases, compliance violations, audit effectiveness, and overall risk distribution.

---

## 🎯 Objectives
- Analyze financial risk metrics across major consulting firms
- Identify trends in fraud cases and compliance violations
- Compare audit effectiveness between firms
- Provide an interactive and user-friendly reporting tool

---
